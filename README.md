# Clean Browser — releases

APK releases of Clean Browser, a small private Android browser with a download manager, torrents and VPN/proxy options.

The app's built-in updater reads this repository's releases. Each release has the APK and a `SHA256SUMS` file; the app checks the checksum and the signing certificate before it installs anything.

Source code: [github.com/The412Banner/CleanBrowser](https://github.com/The412Banner/CleanBrowser) (MIT).
